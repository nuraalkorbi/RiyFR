# RiyFR

RiyFR is an Arabic fake review dataset developed for fake review detection and review authenticity analysis.

## Overview

The dataset was created as part of the Sidq graduation project.

### Task

Binary Classification

- 0 = Genuine Review
- 1 = Fake Review

## Dataset Information

Language: Arabic

Domain: Google Maps Reviews

## Files

- data/riyfr.csv
